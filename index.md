# Liquid Design System

Bienvenue dans la documentation du design system.

Cette documentation centralise les règles d’usage, les composants, les patterns et les principes de conception utilisés dans nos interfaces.

## Objectifs

- Documenter les composants de manière claire.
- Aligner design et développement.
- Relier les composants Figma aux widgets Flutter.
- Préparer une documentation exploitable par une IA.

## Sources liées

- Figma : composants, variants, variables et maquettes.
- Widgetbook : widgets Flutter réels et cas d’usage.
- Markdown : source de vérité documentaire.
