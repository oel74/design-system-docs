# Règles design system pour IA

Cette page centralise les règles que les assistants IA doivent respecter lorsqu’ils génèrent ou modifient une interface basée sur le design system.

## General rules

- Utiliser les composants existants avant de créer un nouveau composant.
- Respecter les variants documentés.
- Respecter les règles d’usage propres à chaque composant.
- Ne pas inventer de nouveaux tokens sans validation.
- Privilégier les widgets Flutter existants dans Widgetbook.
